# 📝 Todo List App

Une application de liste de tâches simple, réalisée en **HTML**, **CSS** et **JavaScript** vanille (sans framework ni dépendance).(test commit)

## ✨ Fonctionnalités

- Ajouter une tâche
- Marquer une tâche comme terminée / en cours
- Supprimer une tâche
- Filtrer les tâches : **Toutes** / **En cours** / **Terminées**
- Supprimer toutes les tâches terminées en un clic
- **Persistance locale** : les tâches sont sauvegardées dans le `localStorage` du navigateur (elles restent après rafraîchissement de la page)

## 🗂️ Structure du projet

```
todo-list-app/
├── index.html    # Structure de la page
├── style.css     # Styles et mise en page
├── script.js     # Logique de l'application
└── README.md
```

## 🚀 Utilisation

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/tianairiela/todo-list-app.git
   ```
2. Ouvrir le fichier `index.html` dans votre navigateur.

Aucune installation ni serveur n'est nécessaire.

## 🛠️ Technologies

- HTML5
- CSS3 (flexbox, animations)
- JavaScript (ES6+, `localStorage`)
